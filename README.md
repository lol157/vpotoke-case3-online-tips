# Кейс №3 «Онлайн-чаевые: платформа для ресторанов» (Сеть «Вкус-Сервис»)

Полное инженерное решение кейса №3 чемпионата «ВПОТОКЕ» (репозиторий: https://github.com/lol157/vpotoke-case3-online-tips, ветка [`team_1_case_3`](https://github.com/lol157/vpotoke-case3-online-tips/tree/team_1_case_3)).
Реализовано на стандартной библиотеке **Python 3** (`csv`, `hmac`, `hashlib`, `json`, `http.server`, `unittest`) без внешних серверных зависимостей.

## Быстрый запуск и проверка

```bash
# 1. Прогон встроенных 5 тест-сценариев T3-1..T3-5 в прототипе
python 04_прототип.py --run-tests

# 2. Одиночный запуск CLI на эталонных примерах qr_001 (SUCCESS) и qr_003 (DECLINED)
python 04_прототип.py qr_001.json
python 04_прототип.py qr_003.json

# 3. Генерация 3 аналитических отчётов по реальному payments.csv
python 04_прототип.py --report m_001 e_001

# 4. Запуск полного набора модульных и HTTP-интеграционных автотестов (unittest)
python test_case3.py

# 5. Запуск веб-сервера OpenAPI (порт 8083) и 4-экранной формы чаевых
python app_server.py
# Открыть в браузере: http://localhost:8083/pay?qr=qr_001
```
